# 골목의 밤냥 — 현재 플레이와 기술 구조

> 신규 창작의 기준은 [스토리보드 SSOT](storyboard.md)입니다. [레벨 및 영구 성장 설계](level-design.md)의 보관용 츄르·통조림과 ‘고양이 운동하기’를 구현했습니다.

현재 실제 콘텐츠와 레벨/진화/패시브/생활 아이템/웨이브 수치는 [세 번의 밤 산책](night-campaign.md)에 정리한다. 기존 25개 항목의 전체 기획 중 이번 구현 범위는 3개 지역·8무기·12패시브·6진화·쉼터·짧은 이야기다.

## 전투와 화면

이동 입력만 필요하다. 처음의 자동 조준과 관통·경로·연쇄에 하악질·이동 미끼·벽 반사·멈춘 뒤 기습·밀집 유인을 추가했다. 보유 무기와 패시브는 각각4종까지, 무기6레벨·패시브2레벨이다. 선택지에서 보유 무기 성장과 적절한 진화 짝을 제시한다. 최대 성장 뒤에는 회복/수집 선택지를 제공한다.

고양이는 실제 충돌 도형을 통과하지 못하며 축별 미끄러짐 이동을 사용한다. 괴이는 잔류 기척이므로 벽을 통과한다. 쓰러진 괴이의 경험치·진화 상자는 걸어갈 수 있는 위치로 보정한다. 병뚜껑은 같은 충돌 도형과 월드 경계를 기준으로 반사한다. 미끼는 추적 방향을 바꾸고, 방울은 가까운 괴이를 당긴다. 보스는 밀기·공포·당김에 저항한다.

첫 지역은9분, 공원은11분, 시장은13분에 보스가 등장한다.1분 뒤 일반 증원은 멈추지만 보스는 남는다. 보스를 쓰러뜨려야 승리한다. 도전 난도는 공격 패턴과 적 생성 속도를 바꾼다. 보스 체력 절반 이하부터2단계 패턴을 사용한다.

UI 상태는 menu/stages/shelter/training/story/cats/playing/resuming/upgrading/paused/results다. 전투는 playing일 때만 진행한다. 배경 전환이나 앱 포커스 상실 시 저장·일시 정지하며 진행 중인 업그레이드 선택지도 복원한다.

## 성능과 상한

적500, 아군 투사체400, 적 탄환600, 줍기250. 털64, 미끼·방울·담요 합계12, 시각 효과100, 폭발 예고32(적 장판3개) 상한.64단위 공간 해시로 후보를 좁히고 빠른 탄은 선분 충돌로 검사한다. 대상 ID와 풀 세대 번호를 함께 기록해 재사용된 슬롯을 이미 맞은 적으로 잘못 취급하지 않는다.

상점/쉼터의 픽셀 텍스처는 생성해 재사용하고, 고양이 보호 효과는 완전히 지우는 점멸 대신 반투명 표시로 위치를 유지한다. 배경 장식24개를 직접 그린다. 새 지역의 화단·좌판은 노드 수를 늘리지 않는 도형 배열이다.

## 성장과 저장

`Battle.training_drops`는 보관용 재료를 XP 풀과 별도로 보존한다. 츄르는 30초부터 60초 간격, 통조림은 예정된 엘리트 처치 때 생성한다. 수집 즉시 산책 저장을 요청하고, 종료 때 `NightProgress`가 수집분과 보스 보너스를 한 번 정산한다. 운동은 모든 고양이에 공통이며 새 판 시작 시 레벨과 최대 체력을 고정한다. XP 반경은 `58 × (1 + 운동레벨 × 0.02) + 패시브레벨 × 18`, 최대 체력은 `100 + 운동레벨 × 5`다. 모든 회복과 체력바가 가변 최대 체력을 따른다.

플레이의 **간식**은 `NightProgress`에서만 관리한다. 90초당1(최대8), 승리3, 단서1을 정산하고 가구를 통해 새 무기를 배운다. 유료 토큰으로 공격력이나 무기를 구매하지 않는다.

외형 상점의 **유료 토큰**은 별도 캐시/서버 원장을 쓴다. 실제 결제 활성화에 필요한 작업은 [상점 문서](token-shop.md)에 있다.

`user://night-walk.dat`는 산책 snapshot version5다. version3/4를 이관하며 기존 산책의 운동은 0레벨이다. 새 형식은 재료 수집량·남은 재료·다음 생성 시점·운동 레벨·최대 체력과 기존 전투 상태를 포함한다. 로컬 설정은 `settings.cfg`, 진행은 산책 경로 뒤 `.progress.cfg`(version2)다. 결과는 `.progress.cfg.pending`에 수집분과 보너스를 별도로 기록한 뒤 산책 ID로 중복 없이 정산한다. 이전 pending도 복원하고, 이미 정산한 산책은 이어하기로 다시 열지 않는다. 저장 실패 시 재료 차감과 운동 레벨을 함께 롤백한다. 손상된 신규 진행 필드는 자동 초기화·덮어쓰지 않는다.

## 검증 범위

`bash scripts/test-game.sh --render`는 전투, 고양이 고유 공격, 외형 상점, 캠페인/쉼터, 입력·저장, 전체 진행·부하, 실제 창 렌더링을 검사한다. 지역과 난도별 전체 진행은 `tests/full_run_test.gd -- --stage=0 --difficulty=0` 인자로 실행할 수 있다.

전체 진행 봇은 무적이며 목표 지점을 향해 경험치를 줍는다. 보스 처치 가능성과 저장 재현성의 검사 도구이며 실제 유저 승률이나 모바일60fps를 증명하지 않는다. [사람 플레이테스트](playtest-guide.md), 실제 중저가 기기의 발열·배터리, 구매 연동 검증은 별도로 필요하다. 모바일 실행법은 [README](../README.md)를 따른다.
