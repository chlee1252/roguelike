# 첫 플레이테스트 진행표

현재 버전은 세 지역·8무기·12패시브·6진화·쉼터가 있는 플레이테스트용 빌드다. 무적 봇은 진행/저장/풀 한계를 검사하며 실제 난도를 평가하지 않는다. 아래 수치는 내부 평가 방향이며 외부 업계 기준이나 이미 측정한 결과가 아니다.

## 먼저 확인할 질문

- 설명 없이 이동과 자동 공격을 이해하는가?
- 첫 업그레이드에서 무엇이 달라질지 설명할 수 있는가?
- 죽었을 때 원인이 탄환/접촉/장판 중 무엇인지 아는가?
- 지루해서 그만둔 시점과 압도되어 그만둔 시점이 각각 언제인가?
- 다음 판에 바꾸고 싶은 무기나 이동 방식이 구체적으로 있는가?
- 쉼터에 돌아와 새 무기·다음 지역 중 목표 하나를 스스로 고르는가?
- 단서 세 개를 본 뒤 고양이가 왜 이 장소에 왔는지 이해하는가?

## 한 사람의 세 판

1. 첫 판: 힌트 없이 일반 골목. 조작을 막는 문제가 아니면 도와주지 않는다.
2. 둘째 판: 본인이 시작 버릇과 조합을 바꾸도록 한다. 첫 판과 달라진 행동을 관찰한다.
3. 셋째 판: 쉼터에서 가능한 해금을 직접 고르고 다시 산책. 새 지역을 열었다면 그곳을 선택하게 한다.

각 판의 지역/난도/시작 버릇, 죽거나 완료한 시간, 마지막 위험, 사용 무기4종, 진화 여부, 단서 발견, 자발적 재도전 여부를 기록한다. 희망자에게만 기록과 화면 수집을 설명하고 동의를 받으며, 계정·결제 정보는 수집하지 않는다. 빌드 자체에는 원격 행동 분석 전송을 추가하지 않았다.

## 조정 기준

- 공격 방식의 설명을 틀리면 콘텐츠 추가 전에 문구와 시각 신호를 고친다.
- 사망 원인을 모르겠다는 답이 반복되면 공격 예고/색 대비/피격 피드백을 고친다.
- 같은 구간에서 무료함이 반복되면 무리와 휴식 간격을 조정한다.
- 특정 무기가 항상 선택되면 단순 피해뿐 아니라 안전성·사용 조건·사거리·획득 순서를 함께 본다.
- 대부분이 첫 판에 끝까지 가거나 거의 시작하자마자 죽으면 일반 난도를 다시 조정한다. 작은 표본의 승률을 출시 기준으로 단정하지 않는다.
- 첫 보스를 쓰러뜨려도 쉼터에서 할 일을 모르겠다면 후일담과 다음 목표 안내를 먼저 고친다.

구매 시스템은 아직 일반 빌드에서 비활성이다. 실제 스토어·로그인·영수증 검증을 연결한 후 취소/보류/연결 끊김/중복 거래/복구/환불을 별도로 시험해야 한다. 미완료 상태에서 유료 상품을 판매하지 않는다.
