# 골목의 밤냥 — 스토리보드 SSOT

버전 1 · 2026-09-12 · 상태: 채택한 창작 기준. 주인 수색·재회 문구, 괴이·보스 픽셀 도형, 쉼터 운동·재회 아트와 발견 기록 재생을 런타임에 반영했다. 장면별 추가 컷과 전용 환경음은 아래 제작 디렉션으로 남긴다.

집 가는 길을 까먹은 고양이들이 주인이 자신을 찾으러 올 때까지 한국 동네의 밤길에서 버틴다. 밤마다 나타나는 귀신과 괴이를 피하고 물리치며, 모아 온 먹거리로 몸을 단련하고 다시 밤을 맞는다.

## 문서의 권한

이 파일은 세계관·인물의 동기·이야기 순서·에셋·문구의 단일 기준이다. 창의적인 구현을 시작하기 전에 읽고, 설정을 바꾸면 이 파일을 먼저 수정한다. 맵 진행·재화·운동 수치는 [레벨 및 영구 성장 설계](level-design.md)가 담당한다. 실제 구현 현황은 [캠페인 구현 사양](night-campaign.md)에 따로 기록한다.

기존 `cat-game-design.md`, `cute-theme.md`, `night-campaign.md`의 서사와 충돌하면 이 파일이 우선한다. 기존의 ‘밥을 주던 사람이 새끼 고양이를 돌보고 있었다’는 결말은 새 캠페인의 결말로 사용하지 않는다. 과거 문서와 코드가 새 기준을 이미 구현했다는 뜻은 아니다.

## 바뀌지 않는 설정

- 여기서 ‘길고양이들’은 지금 길 위에서 지내는 고양이들이다. 이 캠페인의 주인공들은 돌아갈 집과 자신을 찾는 주인이 있지만 집으로 가는 길을 잊었다. 유기당했다는 반전을 넣지 않는다.
- 배경은 가상의 한국 도시 서림시의 빌라 골목·어린이공원·재래시장이다. 고양이는 익숙한 냄새가 남은 동네를 벗어나지 않고, 안전한 기다릴 곳을 옮겨 다닌다.
- 주인은 밤에도 고양이를 찾는다. 우산, 밥그릇, 이동장 담요와 멀리 들리는 부르는 소리로 수색이 가까워지고 있음을 보여준다. 모든 고양이가 한 주인의 고양이라는 설정은 고정하지 않는다.
- 밤에는 귀신·괴이·한국적인 몬스터가 실제로 나타나 고양이를 위협한다. 실물 강아지나 청소기를 주적처럼 보이게 하는 방향은 대체한다.
- 고양이는 네 발로 걷고 냄새를 맡고 하악질하고 몸을 숨긴다. 대사나 인간형 무기 자세 없이 행동으로 감정을 표현한다. 기존 생선뼈·털뭉치·공 등의 공격은 놀이와 방어 행동으로 유지한다.
- 기계적으로 체력 0은 사망/패배다. 화면에서는 쓰러짐 → 암전 → 쉼터에서 깨어남으로 표현하며 영구적인 죽음이나 부활 주문을 설정하지 않는다. 수집물과 운동 성장은 남는다.
- 핵심 감정은 ‘낯선 밤의 불안 → 작은 생존 성공 → 다시 해볼 용기 → 익숙한 손과 재회’다. 고양이의 귀여움과 적의 위협이 함께 읽혀야 한다.

## 캠페인 스토리보드

각 장면 ID는 에셋 요청·문구·구현 작업의 공통 참조 키다. 한 장면당 1~3컷, 한 컷 문구는 최대 두 줄을 기본으로 하며 모바일에서 검수한다. 최초 감상 후 건너뛰기와 발견 기록 재생을 제공하는 것이 목표다.

| ID / 발생 조건 | 화면과 행동 | 문구 초안 | 필요한 에셋·소리 |
|---|---|---|---|
| SB-00 / 새 게임 첫 진입 | 갈림길에서 고양이가 양쪽을 바라본다. 창문 불빛이 하나씩 꺼지고, 담장 너머 사람이 고양이를 부른다. | 집으로 가는 길이 생각나지 않는다. / 익숙한 목소리가 올 때까지, 여기서 기다리자. | 한국 빌라 갈림길, 고양이 귀 반응, 먼 호출과 저녁 생활 소음 |
| SB-01 / 첫 쉼터 | 처마 아래 상자에 고양이가 웅크린다. 다른 고양이의 발자국과 비어 있는 자리가 보인다. | 오늘 밤은 이곳에서. | 상자·수건·먹거리 보관함, 약한 빗소리 |
| SB-02 / 골목 시작·단서 발견 | 골목 입구의 그림자가 몸체와 다른 방향으로 움직인다. 고양이가 접힌 노란 우산에 뺨을 비빈다. | 이 우산 냄새를 알고 있다. | 우산 단서, 가로등 그림자 괴이, 작은 냄새 입자 |
| SB-03 / 골목 보스 처치 | 장승 그림자가 흩어지고 공원 방향 가로등이 켜진다. 풀 묻은 우산 끝을 맡는다. | 공원 쪽에서도 익숙한 냄새가 난다. | 장승 퇴장, 켜지는 가로등, 공원 표지 |
| SB-04 / 공원 시작·단서 발견 | 빈 그네가 먼저 움직인다. 벤치 아래 별 스티커 밥그릇에 새 먹이가 놓여 있다. | 누군가 방금 다녀갔다. | 빈 그네, 밥그릇, 새 발자국, 쇠사슬 소리 |
| SB-05 / 공원 보스 처치 | 그네 귀신이 사라지자 시장 쪽에서 방울 소리와 고양이를 부르는 목소리가 들린다. | 이번에는 조금 더 가깝다. | 멈춘 그네, 별빛시장 간판, 가까워진 호출 |
| SB-06 / 시장 시작·단서 발견 | 닫힌 좌판 사이 도깨비불이 켜진다. 통로 끝 열린 이동장에 익숙한 담요가 있다. | 집에서 맡던 냄새다. | 좌판·차양·도깨비불·이동장 담요 |
| SB-07 / 시장 보스 처치·첫 결말 | 시장 도깨비가 흩어지고 새벽빛이 든다. 주인의 손이 낮게 다가오고 고양이가 냄새를 맡은 뒤 이마를 댄다. | 찾았다. / 이제 집에 가자. | 손·고양이 재회 컷, 따뜻한 이동장, 새벽 생활 소리 |
| SB-R1 / 어느 맵에서든 패배 | 귀가 내려가고 몸을 웅크린 뒤 암전. 쉼터 수건 위에서 눈을 뜬다. 모아 온 재료가 결과에 나타난다. | 잠깐 쉬어 가자. / 모아 온 먹거리는 그대로 있어요. | 비유혈 패배·기상 포즈, 결과 재료 아이콘 |
| SB-R2 / 운동 구매 성공 | 짧게 달리거나 앞발을 뻗고, 운동 후 보상 간식을 먹고 그루밍한다. | 다음 밤을 위해 조금 더 튼튼하게. | 수염 놀이·기지개·식후 그루밍, 능력치 변화 |

단서를 놓쳐도 보스 처치 후 해당 기록을 열어 서사가 막히지 않게 한다. 패배는 단서를 지우지 않지만 다음 지역은 보스 처치로만 열린다. 마지막 재회는 현재 선택한 고양이를 보여주는 공통 결말이다. 이후 반복 플레이는 ‘밤길의 기억’으로 표시해 다시 길을 잃었다는 사건을 반복하지 않는다. 다른 고양이 선택은 같은 구조의 별도 재회 이야기로 해석한다.

## 괴이와 에셋 디렉션

아래 존재는 한국의 생활 공간과 설화 모티프에서 창작한 게임 캐릭터다. 실제 민속의 정설이라는 설명은 붙이지 않는다.

| ID / 역할 | 실루엣과 행동 | 창작 시 지켜야 할 것 |
|---|---|---|
| EN-01 그림자 발자국 / 추적 | 몸보다 긴 검은 발자국이 모여 낮은 덩어리로 기어온다. | 바닥 장식과 구분되는 밝은 외곽선 |
| EN-02 처녀귀신 / 원거리 | 긴 머리와 흰 옷, 떠 있는 소매가 공격 방향을 가리킨다. | 피·상처·사체 묘사 없이 머리·옷의 운동으로 공포 표현 |
| EN-03 우산 괴이 / 돌진 | 주인 없는 접힌 우산이 곧게 서서 방향을 고정한 뒤 돌진한다. | 단서인 노란 우산과 색·형태·크기를 다르게 제작 |
| EN-04 도깨비불 / 장판 | 땅 위 떠 있는 불씨가 원을 그리고 그 자리에 불이 번진다. | 실제 불꽃 이전에 경계와 발동 시간을 보여줌 |
| EN-05 망태 괴이 / 엘리트 | 빈 망태가 부풀어 길을 막고 기척을 뿜는다. | 고양이를 잡아먹거나 학대하는 연출 없음 |
| BS-01 골목 장승 그림자 / 골목 보스 | 담장보다 높은 목재 얼굴의 그림자, 아래로 퍼지는 그림자 공격 | 한국 골목 배경과 장승 모티프를 결합한 창작물 |
| BS-02 빈 그네 귀신 / 공원 보스 | 그네 줄과 긴 소매가 가로·세로로 흔들린다. | 어린이 피해 서사 없이 비어 있는 놀이기구의 기척으로 표현 |
| BS-03 새벽시장 도깨비 / 시장 보스 | 차양 아래 큰 뿔 실루엣, 원형 도깨비불과 바닥 내려치기 | 앞선 두 지역의 회피 학습을 종합하는 동작 |

환경은 남색·먹보라 밤바닥과 낮은 채도의 벽, 안전을 느끼는 창문·쉼터는 따뜻한 노랑을 쓴다. 고양이는 기존 네 종의 밝은 픽셀 실루엣을 유지한다. 적 탄환과 공격 예고는 배경보다 밝고, XP·재료와 형태까지 달라야 한다. 화면 전체의 밝기를 낮춰 밤을 표현하지 않는다.

한국성은 빌라 주소판, 분리수거장, 공원 운동기구, 시장 차양·셔터·손글씨 가격표에서 드러낸다. 서양 묘지·중세 성·일본 도리이를 기본 배경으로 사용하지 않는다. 고양이·보스·공격 예고의 읽힘이 장식보다 우선이다.

## 텍스트와 제작 규칙

서사 문구는 짧은 관찰문, 기능 문구는 무엇이 저장되거나 바뀌는지 명확한 존댓말로 쓴다. ‘사냥하러 출정’, ‘세상을 구할 선택받은 고양이’, 주인이 버렸다는 암시를 넣지 않는다. 실패 결과 제목은 ‘잠깐 쉬어 가자’, 승리 결과는 ‘이 길은 이제 괜찮아’, 성장 메뉴명은 정확히 ‘고양이 운동하기’를 사용한다.

에셋·카피 작업의 요청서에는 다음을 포함한다.

1. 이 문서 링크와 장면/괴이 ID, 등장 맵 및 발생 조건.
2. 전달할 감정과 실제 플레이에서 필요한 식별 정보.
3. 대상 화면·크기·픽셀 스타일·필요한 애니메이션 상태.
4. [레벨 설계](level-design.md)의 관련 규칙, 예고와 판정의 일치 여부.

완료 검수에서는 ‘주인이 찾는 동안 버틴다’는 동기가 유지되는지, 한국 밤동네가 읽히는지, 실패 뒤 수집물과 성장의 지속이 전달되는지 확인한다. 새 고양이·지역·결말을 추가하면 먼저 이 파일에 ID와 서사 역할을 등록한다.
