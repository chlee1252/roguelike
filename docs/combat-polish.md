# 문구·전투 피드백·사운드 개선

## 화면과 고양이

‘버릇’은 ‘무기’, ‘산책 기억’은 플레이 보상인 ‘간식’, ‘진화 짝’은 ‘진화에 필요한 강화’로 정리했다. 메뉴는 ‘스테이지 선택’, 난도는 ‘보통/어려움’이다. 진화 위치에는 물음표 대신 작은 택배 상자와 ‘진화’ 표시를 그린다. 간식은 기존 저장 값 `memories`를 그대로 사용하므로 잔액이 유지된다.

제목과 버튼에는 둥근 Jua, 작은 설명에는 Pretendard Regular를 쓴다. Jua는 [Google Fonts 공식 저장소](https://github.com/google/fonts/tree/main/ofl/jua)에서 가져왔으며 OFL 원문을 폰트와 함께 포함한다.

| 고양이 | 기본 무기 | 초반 움직임 |
|---|---|---|
| 치즈냥 | 생선뼈 | 앞에 있는 적을 관통하며 이동 |
| 턱시도냥 | 장난감 공 | 적이 모인 곳에 공을 튕기기 |
| 삼색냥 | 하악질 | 가까이 온 적을 밀어내며 탈출 |
| 눈송이냥 | 털뭉치 | 계속 걸어 적을 털 자국으로 유도 |

새 게임에는 선택한 고양이의 기본 무기 하나가 적용된다. 기존 진행 중 저장을 이어 하면 해당 판의 무기를 유지한다. 이전 전역 시작 무기 설정은 저장 파일 호환성을 위해 남겨 두지만 새 게임에는 적용하지 않는다. 쉼터의 기존 시작 무기 선택 화면은 무기 도감으로 바뀐다. 유료 전용 공격력·무기는 없고 네 기본 무기는 누구나 레벨 업에서 획득할 수 있다.

## 타격감

- 명중 순간 십자 섬광, 피해 25 이상 숫자, 처치 순간 빛과 파편을 표시한다.
- 투사체에 짧은 잔상을 그려 공격 방향을 읽기 쉽게 한다.
- 3초 안에 처치를 이어 가면 5마리부터 연속 처치를 표시하고 10마리 단위로 짧은 보상 소리를 낸다. 추가 공격력이나 재화 보너스는 없다.
- 처치 순간 최대 2논리픽셀 화면 흔들림을 적용한다. 설정에서 흔들림·피해 숫자를 끌 수 있으며 진화의 큰 확산 효과도 함께 줄어든다.
- 실제 진화에만 확산 고리와 긴 상승 음계를 사용한다. 일반 레벨 업 선택은 짧은 소리다.
- 피해 숫자는 한 화면 최대 12개이며 가까운 숫자는 겹쳐 그리지 않는다. 효과 목록은 기존 100개 상한, 일반 효과음은 8보이스 상한을 유지한다. 중요 알림용 2보이스와 음악용 2보이스가 별도로 있다. 짧은 효과음은 종류별 재생 간격을 제한한다.

## 음악과 효과음

Suno나 외부 음원을 사용하지 않았다. `scripts/compose-music.py`가 프로젝트용으로 구성한 멜로디·반주·드럼을 표준 Python만으로 합성한다. 음악은 런타임에 생성하지 않고 미리 만든 WAV 파일을 재생한다.

| 파일 | 용도 | 길이 / 템포 |
|---|---|---|
| `assets/audio/shelter.wav` | 메뉴·쉼터·이야기 | 20초 / 96 BPM |
| `assets/audio/night-walk.wav` | 일반 전투 | 30초 / 128 BPM |
| `assets/audio/boss.wav` | 보스전 | 약 25.26초 / 152 BPM |

22,050 Hz, 16비트 모노 PCM이다. Godot WAV 가져오기 압축을 끄고 반복 끝을 마지막 샘플 인덱스(프레임 수 − 1)로 설정한다. 2개 플레이어가 음악 전환을 부드럽게 연결하며 레벨 업 선택 화면에서는 음악을 낮춘다. 음악과 효과음은 각각 켜고 끌 수 있다. 이전 버전에 소리를 꺼 둔 사용자는 음악도 처음에는 꺼진 상태로 이관한다. 일시정지·앱 백그라운드에서는 소리를 멈춘다.

생선뼈, 공 튕김, 하악질, 방울, 폭발, 피격, 경험치, 처치, 강화, 진화, 연속 처치, 승리 효과음을 `CombatAudio`에서 합성한다. 파일 재생 또는 믹서 검증이 음악의 취향·장시간 피로도 평가까지 대신하지는 않는다.

## 재현

```sh
python3 scripts/compose-music.py
bash scripts/test-game.sh --render
godot --headless --path . --script tests/audio_mix_test.gd
```

`feedback_test`는 고양이/전투 테스트와 함께 음악 전환·반복·분리 음소거·백그라운드 정지·연속 처치 만료·효과 상한을 검사한다. `audio_mix_test`는 [Godot AudioEffectCapture](https://docs.godotengine.org/en/stable/classes/class_audioeffectcapture.html)로 실제 오디오 버스 샘플을 받아 곡 끝에서 시작으로 실제 반복되는지, 무음·클리핑·정지 후 잔류 소리를 검사한다. 청감 및 실제 모바일 스피커의 음량 균형은 별도 플레이테스트 대상이다.
