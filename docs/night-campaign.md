# 세 번의 밤 산책 — 구현 사양

이번 확장은 출시 전 플레이테스트를 위한 캠페인 버전이다. 무기·진화·쉼터·지역과 짧은 이야기까지 구현했으며, 실제 이용자의 재미·난도 검증이나 정식 출시를 완료했다는 뜻은 아니다.

## 플레이 흐름

산책길 선택 → 자동 공격과 이동 → 경험치로 무기/패시브 선택 → 물건의 냄새 발견 → 엘리트가 남긴 진화 상자로 진화 → 스테이지 보스 처치 → 짧은 후일담 → 쉼터에서 새 무기 준비 → 다음 지역/도전 산책.

처음에는 치즈냥, 해솔빌라 골목, 생선뼈·털뭉치·장난감 공·하악질이 열린다. 고양이별 기본 무기는 치즈냥=생선뼈, 턱시도냥=장난감 공, 삼색냥=하악질, 눈송이냥=털뭉치다. 쉼터의 ‘무기 도감’에서 레벨 업에 등장할 무기를 확인한다. 무기는 8종 중 최대 4종, 패시브는 12종 중 최대 4종을 한 판에 보유한다. 슬롯이 가득 차면 새 종류는 선택지에서 빠지고 보유 중인 종류의 레벨은 계속 올릴 수 있다. 공격은 전부 자동이다.

## 세 지역과 두 난도

| 지역 | 공간의 차이 | 보스 등장 / 일반 증원 종료 | 전용 보스 패턴 |
|---|---|---|---|
| 해솔빌라 골목 | 빌라 외벽, 편의점, 상자와 낮은 담장 | 9분 / 10분 | 멍멍 꿈대장: 부채꼴 탄막과 바닥 예고. 체력 절반부터 탄 수 증가 |
| 달잠 어린이공원 | 길게 뻗은 화단 사이 통로, 그네 | 11분 / 12분 | 깍깍 그네지기: 가로·세로 깃털길 교대, 넓은 통과 틈. 후반 바닥 공격 |
| 새벽 별빛시장 | 넓은 좌판이 만드는 좁은 골목, 줄무늬 차양과 과일 상자 | 13분 / 14분 | 웅웅 시장청소왕: 세 발 너비의 틈이 회전하는 원형 탄막. 후반 바닥 공격 |

이전 지역의 보스를 처치하면 다음 지역이 열린다. 첫 보스 처치 후 도전 산책이 열린다. 도전은 일반 적 생성 속도 +20%, 일부 공격의 예고 시간 단축, 첫 보스 탄 수 증가, 공원 보스 후반 틈 축소, 시장 보스 추가 바닥 공격을 적용한다. 적 체력 배율만 높이는 모드는 아니다.

시간이 끝나도 보스가 살아 있으면 전투는 계속된다. **보스 처치만 클리어**다. 유료 배경 테마는 이 지역들 위에 적용되는 외형 팔레트이며 지역 개방이나 난도에 영향을 주지 않는다.

## 첫 10분

| 시간 | 실제 이벤트와 의도 |
|---|---|
| 0~1분 | 가까운 기본 괴이로 자동 공격을 확인. 40초 뒤 까마귀 혼합, 45초에 우산 냄새 표시 |
| 1~2분 | 90초에 생활 아이템 등장. 위험을 피해 주우러 갈지 판단 |
| 2~3분 | 120초 엘리트 청소대장과 돌진 강아지. 엘리트 처치 시 진화용 냄새 |
| 3~4분 | 210초 생활 아이템, 220초 이후 분무기 예고 장판 |
| 4~5분 | 240초 엘리트 청소기. 선택한 무기 조합으로 큰 적 처리 |
| 5~6분 | 일반 무리에 청소기·까마귀 대장 혼합. 330초 생활 아이템 |
| 6~7분 | 360초 엘리트 청소대장. 무기 6레벨 + 전용 보조 아이템 2레벨이면 진화 상자를 주워 진화 |
| 7~8분 | 450초 생활 아이템. 음식·상자·밥그릇으로 보스전 준비 |
| 8~9분 | 480초 엘리트 까마귀 대장. 남겨둔 냄새로 마지막 조합 완성 |
| 9~10분 | 멍멍 꿈대장. 체력 절반부터 2단계. 처치하면 후일담과 쉼터 보상 |

공원에는 600초, 시장에는 600초·720초 엘리트를 추가해 후반이 단순 대기로 흐르지 않도록 했다. 생활 아이템은 90초부터 120초 간격으로 보스 등장 전까지 나타난다. 음식은 별도의 23~32초 주기로 계속 나온다.

## 무기 8종

기본 수치 및 레벨별 문구는 `NightContent.weapon_note`, 실제 판정은 `Battle`에 있다. 모두 6레벨이며 직선/경로/연쇄/공포/미끼/반사/매복/유인의 역할을 나눴다.

| 무기 | 자동 발동과 조작의 의미 | 최대 레벨 변화 |
|---|---|---|
| 생선뼈 툭툭 | 근처 괴이에게 직선 관통. 적이 일렬이 되는 위치로 이동 | 기본 피해 27, 3마리 관통 |
| 털뭉치 발자국 | 실제로 걸은 자리에만 털 생성. 쫓아오는 적을 경로로 유인 | 털 틱 피해 5, 느려짐, 빠른 생성 |
| 통통 장난감 공 | 맞지 않은 가까운 적에게 연쇄. 밀집한 무리에 강함 | 피해 34, 공 2개, 짧은 주기 |
| 하악! 저리 가 | 적이 반경 안에 들어오면 피해·넉백·공포. 둘러싸임 탈출 | 피해 31, 가까운 적 탄환 제거 |
| 바스락 비닐봉지 | 이동 거리 90마다 뒤에 미끼. 추적 대상을 바꾸고 시간이 지나면 터짐 | 필요 거리 65, 두 갈래 미끼 |
| 병뚜껑 핀볼 | 가까운 적에게 발사. 외벽·월드 경계에 튕길 때 피해 증가 | 2발, 짧은 주기, 반사 지점 범위 피해 |
| 상자 매복 | 1.3초 멈춰 충전한 뒤 움직이면 앞발 기습. 충전 중에는 발동하지 않음 | 넓은 충격파 2회, 기습 직후 짧은 무적 |
| 딸랑 방울놀이 | 밀집 지역에 방울을 보내 주변 괴이를 끌어당기며 주기 피해 | 더 긴 지속·강한 당김·짧은 주기 |

방울로 모은 적에게 공을 튕기거나, 비닐 미끼로 털 경로 위에 적을 유인하거나, 하악질로 공간을 확보한 뒤 상자 매복을 충전하는 조합이 가능하다. 보스는 공포·밀어내기·당김에 저항한다. 미끼·방울·담요 합계는 12개로 제한한다.

## 진화 6종

각 무기 6레벨 + 짝 패시브 2레벨 + 엘리트가 남긴 냄새를 주우면 진화한다. 냄새 하나는 하나의 무기만 진화시킨다. 조건을 아직 갖추지 못하면 냄새가 사라지지 않는다.

| 무기 | 짝 패시브 | 진화 | 변화 |
|---|---|---|---|
| 생선뼈 | 생선 간식 | 와다다 생선뼈 | 2발, 각 5마리 관통, 주기 단축 |
| 털뭉치 | 두꺼운 겨울털 | 온 골목이 내 털 | 잔향 피해와 퇴치 위치 털 확산 |
| 장난감 공 | 장난감 집착 | 통통 털실공 | 최대 6마리 연쇄 |
| 하악질 | 부푼 꼬리 | 골목의 작은 호랑이 | 반경 100, 주기 1.8초 |
| 병뚜껑 | 벽 타는 감각 | 우당탕 병뚜껑 | 추가 벽 반사 2회, 반사 범위 피해 확대 |
| 상자 매복 | 상자가 좋은 날 | 상자 속 번개발 | 기습 시 공포·넉백, 무적 0.8초 |

비닐과 방울은 6레벨 고유 효과를 완성하며 별도 진화는 없다. 선택지는 조건 없는 진화를 광고하지 않는다.

## 패시브 12종

수치는 한 레벨 기준, 최대 2레벨이다.

| 패시브 | 효과 |
|---|---|
| 생선 간식 | 생선뼈 피해 +15% |
| 두꺼운 겨울털 | 털 반경 +5 |
| 장난감 집착 | 장난감 공 주기 −12% |
| 깨끗한 발바닥 | 이동 속도 +8% |
| 튼튼한 수염 | 획득 범위 +18 |
| 부푼 꼬리 | 하악질 공포 +0.4초, 공포 대상 추가 피해 +10% |
| 벽 타는 감각 | 병뚜껑 벽 반사 +1 |
| 상자가 좋은 날 | 상자 숨기 충전 +0.5초, 매복 충전 시간 −0.15초 |
| 동네 사람의 호의 | 즉시 음식 회복량 +20% |
| 푹신한 발젤리 | 받는 피해 −8% |
| 바스락 호기심 | 비닐·방울 유인 반경 +15 |
| 웅크린 집중력 | 1초 멈추면 피해 +12% |

## 줍는 생활 아이템

기존 참치(25 회복), 츄르(12 회복+이동), 고등어살(8 회복+지속 회복)에 추가했다. 획득 시 자동 발동하므로 버튼이 늘어나지 않는다.

- 흩어진 사료: 6 회복 후 근처에 4씩 회복하는 사료 세 조각을 흩뜨린다. 조각을 주울 동선을 선택한다.
- 캣닢 주머니: 8초 동안 이동 기본 속도 120, 무기 시계 1.35배. 츄르와 이동 속도는 중첩하지 않는다.
- 바스락 종이봉투: 반경 150 안의 괴이를 밀어내고 3초 공포. 보스는 저항한다.
- 익숙한 담요: 6초 지속되는 자리. 안에 머무르면 0.5초마다 2 회복과 짧은 보호를 갱신한다.

## 짧은 미스터리와 쉼터

빈 밥자리 → 노란 우산의 풀 냄새 → 공원의 별 스티커 밥그릇 → 별빛시장 이동장 담요. 마지막 지역에서 밥을 주던 사람이 다친 새끼 고양이를 돌보고 있었음을 보여준다. 고양이는 말하지 않으며 찾고, 먹고, 그루밍한다. 각 지역의 단서는 45초 이후 근처의 걸어갈 수 있는 위치에 표시된다. 보스를 처치해도 해당 단서를 얻어 이야기가 막히지 않는다.

‘간식’은 플레이 보상이다. 90초마다 1개(최대 8), 승리 +3, 단서 발견 +1. 이 재화로 쉼터 물건을 들여놓는다. 유료 토큰과 저장소·용도를 분리했다.

| 쉼터 물건 | 간식 비용 | 배우는 무기 |
|---|---:|---|
| 바스락 놀이터 | 3 | 비닐봉지 |
| 병뚜껑 바구니 | 5 | 병뚜껑 |
| 포근한 상자집 | 7 | 상자 매복 |
| 방울 달린 담요 | 9 | 방울놀이 |

물건이 쉼터 그림에 나타나고, 배운 무기는 레벨 업 선택지에 등장한다. ‘발견 기록’에 단서가 모인다. 마지막 지역 완료 후 쉼터에 작은 삼색 고양이가 함께 등장한다. 영구 공격력 구매는 없다.

## 저장과 검사

산책 저장은 version 4이며 version 3의 3무기 저장을 새 배열 구조로 옮긴다. 공포 상태·보조 무기 시계·미끼·매복 충전·지역·난도·이벤트·단서를 저장한다. 기존 유료 외형 캐시는 그대로 쓴다.

`NightProgress`는 결과를 먼저 `.pending` 기록에 저장한 뒤 같은 산책 ID를 한 번만 정산한다. 재실행 시 미완료 정산을 재시도한다. 영구 성장 저장에 실패하면 구매를 롤백한다. 미정산 기록을 복구하지 못하면 새 산책 시작 대신 쉼터에서 재시도를 안내한다.

```sh
bash scripts/test-game.sh --render
# 특정 지역의 전체 진행 검사. 이 봇은 무적이며 인간 난도 평가가 아니다.
godot --headless --path . --script tests/full_run_test.gd -- --stage=1 --difficulty=0
godot --headless --path . --script tests/full_run_test.gd -- --stage=2 --difficulty=1
```

자동 검사만으로 출시 난도·재미·모바일 발열을 확정하지 않는다. 다음 단계는 [사람 플레이테스트](playtest-guide.md)다. 실제 현금 결제의 미연결 항목은 [토큰 상점](token-shop.md)에 별도로 남아 있다.
